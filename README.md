# Majestic-Trade-Log
Majestic Trade Log — это удобный оверлей-калькулятор для перекупщиков в GTA RP (Majestic и др.).

**Что умеет:**
*   🎯 **Авто-считывание баланса:** По нажатию **F10** программа сама распознает наличные и банк прямо с экрана игры (технология OCR).
*   📐 **Умная калибровка:** Подстраивается под любое разрешение экрана. Вы один раз выделяете область с деньгами, и программа запоминает это для каждого разрешения отдельно.
*   📝 **Журнал сделок:** Быстрый ввод доходов и расходов с заметками. Автоматический вычет налога 3% из прибыли.
*   💰 **Чистый итог:** Всегда показывает вашу реальную прибыль (зеленым) или убыток (красным).
*   🗑️ **Удаление по одной:** Если ошиблись — можно удалить конкретную сделку крестиком, не стирая всю историю.
*   💾 **Надежное хранение:** Вся история сохраняется в локальную базу данных (SQLite) и не пропадает после перезапуска.
*   👁️ **Скрытие окна:** Кнопка **F9** мгновенно прячет/показывает калькулятор, чтобы он не мешал в игре.

**Важно:** Запускать `.exe` нужно **от имени администратора** (для работы горячих клавиш поверх игры), а игру ставить в режим **«Оконный без рамок»**.
